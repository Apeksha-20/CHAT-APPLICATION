##DESCRIPTION     

The Real-Time Chat Application is a web-based communication platform that allows users to send and receive messages instantly without refreshing the page. 
This project is developed as part of the Full Stack Web Development internship at CODTECH IT SOLUTIONS.The main objective of the project is to demonstrate real-time
communication between multiple users through modern web technologies.The application is built using Node.js, Express.js, and Socket.IO for real-time communication
between theserver and connected clients. The frontend is developed using HTML, CSS, and JavaScript, which provide a simple and interactive user
interface for sending and receiving messages.
Overall, the Real-Time Chat Application showcases the integration of frontend and backend technologies to create a functional and interactive web application 
capable of supporting multiple users simultaneously.
