# REAL-TIME CHAT APPLICATION

## 📌 PROJECT OVERVIEW

The **Real-Time Chat Application** is a web-based messaging platform that allows multiple users to communicate with each other instantly through a browser. The application demonstrates the implementation of real-time communication using modern web technologies and full stack development concepts.

This project was developed as part of the **Full Stack Web Development Internship at CODTECH IT SOLUTIONS**. The main objective of the project is to build a simple but functional chat system where users can send and receive messages without refreshing the web page.

The system uses **WebSocket technology** through the Socket.IO library, which enables fast and continuous communication between the client and the server. Whenever a user sends a message, it is instantly broadcast to all connected users, making the conversation happen in real time.

The application provides a clean and user-friendly interface where users can enter their name, type messages, and communicate with others connected to the chat server.

## 🔄 WORKING OF THE APPLICATION

1. The user opens the chat application in a web browser.

2. The frontend interface is loaded using HTML, CSS, and JavaScript.

3. The server is created using Node.js and Express.js.

4. Socket.IO establishes a real-time connection between the client and the server.

5. When a user types a message and clicks the send button, the message is sent to the server.

6. The server receives the message and broadcasts it to all connected users.

7. Every connected user instantly sees the message in the chat window.

## ▶️ HOW TO RUN THE PROJECT

Follow these steps to run the project locally:

Step 1: Install Node.js on your system.

Step 2: Download or clone the project folder.

Step 3: Open the project folder in Visual Studio Code.

Step 4: Install required dependencies using the command:

npm install

Step 5: Start the server using the command:

node server.js

Step 6: Open your browser and visit:

http://localhost:3000

The chat application will start and users can begin messaging in real time.
